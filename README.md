## 项目章程概要

项目采用游客用户、普通用户、VIP 用户、版主和管理员五类用户定义。账号创建后为游客，只能浏览公开帖子；关联同济身份认证后获得普通用户的发帖、评论和私聊能力；通过支付宝或微信支付购买 VIP 后，获得金色昵称和主页装扮权益。版主和管理员通过管理授权承担社区治理职责。

外部集成包括同济身份认证、支付宝和微信支付。会员权益以服务端核验的支付结果为依据，同一订单只发放一次权益，续费按购买时长累加，会员到期后恢复普通展示并保留普通用户功能。

开发采用增量模型，三个增量分别覆盖账号认证与公开讨论、可靠私聊、会员充值与社区治理。每轮保留计划、构造、测试、评审和回顾记录，需求和实现通过 Issue、PR、CI 和 Release 关联。
